# BitAutor

Independent AI agency from Hanover, Germany – founded in 2019, focused on AI since 2023. We connect the software companies already use with AI where it actually helps, and build custom software where no existing tool fits.

**What we do**

- **AI agents for SMEs** – phone, e-mail, scheduling, sales and company knowledge, connected to existing systems.
- **Custom software, apps and websites.**
- **Our own products:** [Best-AI.org](https://best-ai.org), an AI tool discovery platform, and [CannaRadius](https://www.cannaradius.de), a location-based compliance app.

**How we build agents:** with clear boundaries, handoffs to people and logs. On Best-AI.org our AI agents (OpenClaw, Hermes Agent) work only through MCP servers we built. Each agent has its own service account with only the rights its job needs, deterministic flows decide what it can change, and a person reviews new content before it goes live.

**Stack**

- **AI:** RAG · AI agents · MCP · LLMs (OpenAI, Anthropic Claude, Gemini, local models) · vector search
- **Languages & frameworks:** Python · TypeScript · Next.js · React · Node.js · Flutter
- **Cloud & data:** Google Cloud · Firebase (Firestore) · PostgreSQL · Docker
